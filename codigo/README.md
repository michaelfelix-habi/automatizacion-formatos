# 💻 Carpeta de código

Aquí vivirá el programa que **llena los formatos automáticamente**.

Todavía **no hay código** — primero necesitamos instalar Python y definir los campos
finales. Cuando empecemos a construir, esta carpeta tendrá algo así:

```
codigo/
├── datos/               Configuración fija (compañía, radicadores por ciudad, etc.)
├── plantillas/          Definición de dónde va cada dato en cada formato (coordenadas)
├── generador/           El programa que arma los formatos
└── app/                 La pantalla donde el broker captura los datos
```

Consulta `../documentacion/00_BITACORA_Y_EXPLICACION.md` para entender todo el proyecto.
